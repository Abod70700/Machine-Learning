# Lab - Customer Segmentation with K-Means

In this lab, we applied K-Means clustering on credit card customer data.

## Steps
- Loaded and explored the dataset
- Handled missing values
- Performed feature scaling
- Applied K-Means clustering
- Used the elbow method and silhouette score
- Created customer segments
- Visualized clusters using PCA

## Result
Customers were grouped into different segments based on their spending behavior and financial activity.
