# Lab 5 – Feature Engineering

## Overview

In this lab, feature engineering techniques were applied to improve the dataset and analyze their effect on the machine learning model.

## Tasks Summary

**Task 1:**
Created time-based features from `Order_Time`, including hour of day, day of week, weekend flag, and peak hour indicator.

**Task 2:**
Modified the peak hour rule to include earlier lunch and evening demand.

**Task 3:**
Tested different values of `top_k` (10, 30, 50) for reducing item categories.
The model accuracy remained approximately **0.85** for all values.

**Task 4:**
Applied feature selection to identify important features.
The model accuracy remained approximately **0.85** after feature selection.

## Result

The model achieved an accuracy of about **0.8519**.
